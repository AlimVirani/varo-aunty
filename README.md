# Varo Aunty

A clickable demo (not a working app) of how a jamatkhana varo admin could fill ceremony roles
(first dua, tasbih, ginan, firman, second dua / Gatpat dua) and what volunteers would see on their phones.

Everything is one static file: `index.html`. All names and dates are made up. Nothing is sent anywhere.

Ground rules the demo follows:
- The admin approves every assignment. Nothing is automatic.
- The app never sends a text on its own; every text is an admin pressing a button.
- Volunteers check in for a day and request open varos. They see only open, full, and their own.
- Declines, no-shows and notes stay on the admin side.

## Run locally

Open `index.html` in a browser, or `npx serve .`
